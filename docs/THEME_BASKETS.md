# Theme Baskets

Theme Baskets are Phase 1 offline MVP screens for browsing static educational
groupings. They help users organize research ideas by theme without implying a
recommended portfolio or action.

## Behavior

The Theme Baskets screen shows a fixed local list of educational themes:

- AI Infrastructure
- Cybersecurity
- Cloud Software
- Digital Payments
- Semiconductors
- Healthcare Innovation
- Energy Transition
- Consumer Platforms

Each basket includes a name, description, educational rationale, tags, example
tickers or companies, and non-advisory copy. Users can select a basket to view
its details.

## Data Source

Theme basket data is static and local to the desktop app. It is not downloaded,
personalized, refreshed, ranked, weighted, or tied to live prices.

## Boundaries

The baskets are educational organization aids only. They are not personalized
recommendations, model portfolios, allocation guidance, buy lists, sell lists,
or hold lists.

## Out Of Scope

- live stock APIs or dynamic basket updates
- personalized model portfolios
- buy, sell, hold, or allocation advice
- AI analyst features
- brokerage import or trading execution
- Supabase/auth/cloud sync

## Non-Advisory Notice

Theme Baskets are static educational groupings for user-directed research. They
are not financial advice, investment advice, or recommendations to buy, sell, or
hold any security.
