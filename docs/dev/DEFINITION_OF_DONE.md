# Definition Of Done

Every phase or stage should meet this checklist before a pull request is considered ready for review.

- [ ] Scope matches the stage.
- [ ] No unrelated product features added.
- [ ] No brokerage/trading execution added.
- [ ] No personalized financial advice language added.
- [ ] No hardcoded secrets.
- [ ] Core logic has tests when applicable.
- [ ] UI changes include screenshots in the PR when applicable.
- [ ] README/docs updated when behavior changes.
- [ ] `pnpm lint` passes.
- [ ] `pnpm typecheck` passes.
- [ ] `pnpm test` passes.
- [ ] `pnpm build` passes.
- [ ] Known limitations are documented.
